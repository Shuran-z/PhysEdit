# 评测指标与接入状态

当前 `python -m physedit run phyediting` 接通了生成、单视角 SAM3.1 跟踪和 GravTrace 评分。**Qwen 视觉评估和 V/P 指标尚未接入这个入口**；旧 `public211` 配置调用服务器上的独立脚本，不能据此认定新入口已经支持完整 benchmark 评测。

| 评测内容 | 指标或输出 | PhyEditing 一键入口 | 旧 public211 |
| --- | --- | --- | --- |
| 重力反演 | 请求重力相对偏差、失败率、覆盖率 | 已接入 | 有独立阶段 |
| Qwen 视觉评估 | 异常形变、身份变化、物体穿透、镜头运动、条件不一致；严重程度及文字依据 | 未接入 | 有独立脚本 |
| 视觉质量 | 背景闪烁、轮廓结构差异、相机运动诊断 | 未接入 | 有独立脚本 |
| 参考运动一致性 | 运动区域 mIoU、目标轨迹误差 | 未接入 | 有独立脚本 |

SAM3.1 在当前入口中提供目标观测，不单独输出上述视觉质量指标。`summary.json` 只汇总 GravTrace；视频解码、尺寸、帧率和时间戳检查属于输入验证，不是生成质量评分。

## 配置

示例配置明确列出实际启用的指标：

```json
"evaluation": {"metrics": ["gravtrace"]}
```

省略该字段时同样只使用 GravTrace。计划、汇总和完成文件均记录 `evaluation_metrics`。请求 `qwen`、`vp` 或其他未接入指标会在启动前报错，避免配置存在但评测没有运行。

`generation_runtime.gpu_devices` 统一指定生成和 SAM3.1 的设备映射；未填写时沿用启动进程的 `CUDA_VISIBLE_DEVICES`。`generation_runtime.python` 只指定生成模型环境，控制器和 SAM3.1 使用启动命令的 Python。

## 旧评测的范围

已只读核对旧服务器源码：Qwen 使用条件图及生成视频的一秒片段，输出五类问题的存在性、0–3 级严重程度、文字依据、置信度和证据不足标记。旧脚本声明 Qwen3.5-9B 路径；本次没有加载权重，也没有运行该模型。文件名中旧的 `qwen3_vl` 不能作为实际模型版本证明。

V/P 脚本还依赖参考视频、参考及生成掩膜、相机信息与时间对齐，旧汇总包含完整视频及一秒窗口的部分指标。它们使用旧数据目录和分割流程，不能直接把新的 SAM3.1 轨迹文件作为等价输入。

迁移时需明确模型及提示版本、片段时间、参考输入、掩膜格式和逐例失败记录，再验证统一入口与汇总。Qwen 的视觉判断不等于物理因果验证；参考轨迹一致性也不等于所有合理生成均应复现同一轨迹。

GravTrace 使用冻结的单视角方法，数值是**相对于请求重力的偏差**，不是生成视频已知物理真值的误差。失败及不适用样本完整保留，具体定义见 [评分方法](GENERATION.md)。
