# 训练与评测划分

固定评测集包含T01–T20每类5条，共100条单机位案例，另有80条候补。Genesis与Isaac共同提供训练数据。

| 用途 | 事件范围 | 样本分配 |
| :---: | :---: | :---: |
| 训练 | T01、T02、T04–T10、T12–T18 | 排除测试、候补及同源组后的数据 |
| ID测试 | 上述16类事件 | 固定80条 |
| OOD-1测试 | T03、T20 | 固定10条；两类事件全部留出 |
| OOD-2测试 | T11、T19 | 固定10条；两类事件全部留出 |
| 候补 | T01–T20 | 80条单独保留 |

不另分验证集。来源组包含同轨迹的其他机位、背景变体、临界族、重复、重渲染及已核验跨引擎对应版本。四类OOD事件的其余样本也留出，不进入训练。

[评测协议](PROTOCOL.md)说明参数与结果的报告方式，[执行说明](IMPLEMENTATION.md)提供清单导入命令，[配置](plan.json)中的`evaluation_sets.fixed_core100.training_policy`记录当前训练规则。训练数量按实际库存完成来源组排除后统计；缺源、失败和不适用成员保留原ID及原因。
