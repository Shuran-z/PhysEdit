# 联合训练与测试划分

本目录提供Genesis与Isaac联合划分的[协议](PROTOCOL.md)、[配置](plan.json)和[执行说明](IMPLEMENTATION.md)。输入清单、来源记录、审核日志及候选分配保存在本地。

## 事件与目标容量

训练池包括T01、T02、T04–T10、T12–T18，按完整来源组约80/10/10分配；T03/T20进入OOD-1，T11/T19进入OOD-2。

| 集合 | Genesis | Isaac | 合计 |
|---|---:|---:|---:|
| train | 33,792 | 13,248 | 47,040 |
| val | 4,224 | 1,656 | 5,880 |
| ID | 4,224 | 1,656 | 5,880 |
| OOD-1 | 5,280 | 960 | 6,240 |
| OOD-2 | 5,280 | 2,640 | 7,920 |
| 总计 | 52,800 | 20,160 | 72,960 |

表中为设计容量。组不可拆分时，完整来源关系优先于精确比例；Isaac未计划的事件在配置中为零。

## 分配与发布

分配使用媒体版本、物理配置、临界族、数值区间和已核验的对应关系。所有原记录及历史失败版本保留在来源清单中，缺源或待核验记录进入pending，跨集合冲突进入quarantine。

当前发布状态为候选，`release_ready=false`。来源与质量审核完成后生成冻结清单，训练由版本及SHA校验后的reader加载。生成模型的事件留出和评测指标的开发暴露分别记录。
