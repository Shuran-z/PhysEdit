# 指标

每条生成视频对应一个 Core100 任务：一段仿真参考视频、它的条件帧即第 5 帧，以及写明物理参数的提示词。指标分两组：

- **V**：把生成视频和该任务的参考续段比较。
- **P**：测量生成视频表现出的物理参数。

## V：画面与运动一致性

窗口从条件帧开始，取 5 秒；任一视频先结束则到它结束为止。各帧按物理时间对齐，生成视频按自身帧率计时。生成画面通过条件帧的配准映射到参考画面。

| 指标 | 定义 |
|---|---|
| ADE、FDE | 取被跟踪物体的框中心，来自 SAM 3.1 并做了镜头补偿。逐物体把相对条件帧的位移在 30 Hz 网格上和参考比较，再除以画面对角线。ADE 取时间平均，FDE 取最后一个公共时刻；视频间取中位数。 |
| ADE 比值 | ADE 除以画面完全不动时的 ADE，即参考物体的平均位移。小于 1 才说明比不动更接近参考。 |
| S-IoU、ST-IoU、W-IoU、MSE | 与 Physics-IQ 相同的运动一致性。在 10 Hz 网格上由帧差得到运动掩膜，分辨率 427 × 240、灰度、5 × 5 模糊、阈值 0.03。S-IoU 比较哪里动过，ST-IoU 比较哪里、什么时候在动，W-IoU 比较哪里动、动了多少。MSE 是 RGB 的均方误差。 |
| 运动像素 | 每 0.1 秒在动的像素占比；参考续段为 0.21%。 |
| PSNR、SSIM | 条件帧之后的每个 10 Hz 帧，和同一物理时刻的参考帧比较，RGB、427 × 240，SSIM 用 σ = 1.5 的高斯窗；视频内取平均。 |
| 镜头漂移 | 背景相对首帧的最大位移，除以画面对角线；报告中位数和超过 2% 的视频占比。 |

两行参照给出这些指标的范围。物理正确的视频是参考视频本身，按生成视频的格式重编码。条件帧静止不动表示什么都不动能得多少分。

静止的条件帧 PSNR 为 37.0 dB、SSIM 为 0.976，和物理正确的视频一样高，并高于所有模型。模型之间，PSNR 和运动像素占比的 ρ = −0.92，和镜头漂移的 ρ = −0.96，所以 PSNR、SSIM 反映的是画面稳定，不是物理。

## P：物理参数

参数包括重力 *g*、主接触面摩擦 *μ* 和初速度 *v*，只测任务里有定义的几个。对每条视频的每个参数，[仿真器反演](INVERSION_zh.md)给出一类结果：

| 结果 | 含义 |
|---|---|
| 数值 | 点估计或有界区间 |
| 单侧界 | 只能确定下界或上界 |
| 不可辨识 | 几个分开的取值同样能解释运动 |
| 无法解释 | 没有任何取值能解释运动 |
| 无观测 | 被跟踪物体的可用帧太少 |

| 指标 | 定义 |
|---|---|
| 可解释率 | 1 − 无法解释 − 无观测，即运动能被某个参数值解释的结果占比。 |
| g、μ、v 误差 | 给出数值的结果中，\|测得值 / 提示值 − 1\| 的中位数。μ 的提示值取提示词对被测接触面声明的摩擦；两种材料都有声明时取较大者，和仿真器的组合方式一致。 |
| g、v 响应 τ | 同一模型、同一任务中，提示值不同的每一对视频按测得的不确定带排先后。单侧界按半开区间处理，带重叠的对不判。τ 等于同序对数减反序对数，再除以判出先后的对数；95% 区间按模型与任务的组合重采样。μ 在同一任务内几乎不变，不算响应。 |

只有同一任务、同一格式的物理正确视频本身能给出估计时，结果才计入统计；否则测量本身也解释不了正确的物理。

在 12 个模型之间，可解释率和 ADE 比值的 ρ = −0.90，说明它反映了真实的运动质量。g 的响应和所有 V 指标的 |ρ| 都不超过 0.43：它衡量的是改了提示的物理量之后运动有没有跟着变，这是 V 指标测不到的。
