# PhysEdit

PhysEdit 是一个面向物理可控视频生成的数据集与评测项目。它以桌面上的日常物体交互为基础，通过改变重力、初速度、摩擦、质量和物体间距，研究视频生成模型能否响应物理条件的变化，并保持接触、支撑变化和多物体传递过程的一致性。

数据目录包含20类场景、72,000条视频记录，由Genesis和Isaac两套仿真环境构建。每类场景包含2,640条Genesis记录和960条Isaac记录，覆盖四种背景、五档重力和三个机位。场景包括斜面运动、偏心碰撞、抽取支撑、书本堆叠、多米诺传播及多物体接力。不同引擎和场景变体分别保留身份与参数定义。

每条视频配有三个英文prompt，分别侧重场景与初始条件、预设施力或控制时序、物理条件。三个版本使用相同的关键输入参数，不包含预期事件结果。配套清单提供视频哈希、仿真来源、参数、下载位置和审核状态，下载工具按统一名称组织视频与元数据。

PhysEdit的评测工具结合物理参数反演与事件结果判读。参数反演用于测量生成运动对应的重力、摩擦和初速度；临界边界评测用于检查模型在事件转变附近的响应、跨边界结果变化和事件链一致性。各指标按参考真值、观察范围及测量条件选择适用样本，并报告失败率与有效覆盖率。固定Core100协议包含80个ID案例及两组各10个OOD案例，另设80个候补案例。

## 数据组成

| 项目 | 数量 |
|---|---:|
| 场景配额 | 20 |
| 视频记录 | 72,000 |
| Genesis记录 | 52,800 |
| Isaac记录 | 19,200 |
| 三机位视频组 | 24,000 |
| 按视频SHA-256区分的内容 | 67,532 |
| 英文prompt | 216,000 |

四种背景与五档重力按场景和引擎登记。三个机位与重复内容按来源组处理，不能作为相互独立的物理过程计算样本量。Isaac的T14配额采用T14S弹簧发射场景，保留独立的场景标识及参数定义。

```text
data/<native_scene>/<engine>/<trajectory_id>/videos/<video_id>.mp4
```

文件名统一为`physedit_<engine>_<native_scene>_<trajectory_hash>__cam0N.mp4`。压缩包中的成员名由清单映射到该名称。

## 训练与评测

固定Core100包含80个ID案例、T03/T20的10个OOD案例、T11/T19的10个OOD案例，另有80个候补。T03、T20、T11和T19四类事件从训练中留出。其余16类事件的训练成员需排除测试、候补及同源组，包括其他机位、重复内容、背景变体和已确认的对应版本，不另设验证集。

Core100使用冻结的v6输入。数据目录中的普通prompt提供三个互补视角；比较生成模型时采用相同的prompt变体、条件图和观察范围。事件判读、临界边界和参数反演分别报告结果与覆盖率，缺少真值或不满足测量条件的样本按协议单列。
