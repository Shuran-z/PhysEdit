# T11：按可观察的事件评测

用户已指出：用“末帧世界高度低于−0.10米”定义视频里的跌落过于抽象。该条件属于原仿真的验收记录，保留供追溯；新版视觉任务应直接定义物理事件，再用仿真状态计算对应真值。

## 新事件定义

|事件|判断问题|需要的画面证据|
|---|---|---|
|橡皮撞到笔盒|原橡皮是否与原笔盒实际碰撞？|连续画面中的接触及运动响应，靠近或像素重叠不够|
|笔盒撞到眼镜盒|接力是否传到原眼镜盒？|笔盒／眼镜盒接触及运动响应|
|各物体越缘跌落|该物体是否越过桌缘、失去支撑并开始向下掉？|同一物体在桌缘前后保持身份连续，可以确认失去支撑后的向下运动|
|接触地面（扩展项）|物体是否确实碰到地面？|实际接触画面；没有渲染到地面时不要求判这一项|

主分支先关注原橡皮是否发生越缘跌落；笔盒和眼镜盒的跌落分别输出，不能合成“任意一个物体掉了就算全部成功”。两次碰撞和三个跌落事件组成过程向量，时序必须有各自证据，不能仅由末端结果倒推中间链条。接触先后本身也不证明完整因果归属。

跌落判断取整个登记观察窗内的事件转变，不要求最后一帧还看得到物体。稳定悬挂、仍有支撑、出画、遮挡和身份丢失不能单独作为跌落证据。事件转变被遮挡且无足够前后证据时填“不可判”，不填“未发生”。质量失败继续走独立筛查，保留在总体分母。

## 真值和视觉裁判各做什么

参考端用已保存的仿真接触及轨迹计算事件；生成端用生成视频自己的画面和轨迹判断同一事件。VLM不读取参考结果、临界值或参考轨迹，也不负责决定测试哪个事件。

当前状态适配器仅用于T11的原水平桌面：先确认曾与桌面有接触连接，再寻找越过桌面轮廓、无桌面接触路径并持续下降的见证。使用桌面相对位置，整体平移世界高度不改变判断。1毫米与1/30物理秒是显式记录的测量容差和去噪持续时间，不是“世界坐标−0.10米”的事件语义。接触连接只是保守见证，不是一般的受力支撑求解器；复杂侧接触仍须复核。
