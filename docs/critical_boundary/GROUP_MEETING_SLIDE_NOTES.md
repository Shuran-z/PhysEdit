# 临界距离、因果事件链与物理反演：组会 PPT 素材

整理日期：2026-10-14。建议主讲 10 页、约 12–15 分钟，附 3 页备份。本文是现有协议的展示稿，不替代正式协议；数字来自当前固定库存和审计记录，不代表全部数据已通过 QA。

## 第 1 页｜我们希望视频模型理解什么物理？

**页上结论：同一套 benchmark，从事件结果、因果过程和定量动力学三个层面评测物理生成。**

| 维度 | 核心问题 | 对应评测 |
|---|---|---|
| 临界分支 | 参数略微变化后，模型能否在正确的位置改变结果？ | 距离–准确率曲线、NearAcc、PairAcc |
| 因果事件链 | 结果是否由正确的接触与传递过程产生？ | EventExact、首次错误节点 |
| 物理反演 | 视频中的运动体现了什么物理参数？ | GravTrace 请求重力偏差与覆盖率；速度/摩擦开发模块 |

讲解：一段视频可能跌落结局正确，但下落动力学不符合指定重力；也可能局部抛物运动合理，却在本不应跌落的条件下跌落。三类结果应并列报告，不用任意权重合成总分。

配图：同一场景的两侧参考视频，旁边列“分支—过程—参数”三个问题。

## 第 2 页｜为什么围绕临界距离评测？

**页上结论：从总体平均正确率，推进到受控参数变化下的局部物理敏感性。**

- 固定对象、场景及其他物理条件，只干预一个明确参数。
- 由参考物理系统确定目标事件的临界值或边界区间。
- 将已有视频按参数到边界的距离组织，观察模型接近边界时是否失效。
- 配对检查跨界前后结果是否都正确，再检查下游事件是否正确改变。

讲解：不只检测重力。速度、摩擦、支撑位置、间隙、质量等都可以作为干预量，具体取决于该场景和已有扫描。临界点本身不需要有视频；已有两侧视频与可核验的边界记录即可组织评测。

贡献表述建议：**我们提出以物理事件边界距离组织的受控视频生成评测，并联合检验跨界响应、因果传播和可反演动力学。** “首次”需要系统相关工作核对支持，当前不作绝对声明。

## 第 4 页｜一个评测单元如何定义？

一个评测族固定：**场景 + 引擎/版本 + 物理上下文 + 干预参数 + 目标事件 + 局部边界 + 观察时间窗**。

令实际参数为 θᵢ，参考边界为 θ*，预先固定的有效参数跨度为 L：

```math
d_i=\theta_i-\theta^*,\qquad \rho_i=\frac{|\theta_i-\theta^*|}{L}.
```

- d 保留边界方向；ρ 用于距离分层，同时报告原始物理单位距离。
- L 来自预先声明的参数域，不能根据模型成绩调整。
- 当前建议分箱：Near 为 0 < ρ ≤ 0.05；Mid 为 0.05 < ρ ≤ 0.15；Far 为 ρ > 0.15，均限制在有效局部范围内。分箱仍是待冻结方案。
- θ* 随上下文和目标事件变化，不存在全场景通用的一个临界点。
- 参数在阈值哪一侧，不自动等于事件正负标签；标签取参考状态中的实际结果。

配图：横轴参数，画一条参考边界竖线，在两侧放置已有样本；不要画成已有实测模型曲线。

讲解：可用适用的解析计算或同版本临界搜索记录确定边界。没有绑定精确边界的样本依然可以做分支与事件链评分，只暂不计算精确距离分箱。

## 第 5 页｜主指标：距离、配对与链条

令第 i 个参数点有 Kᵢ 次预登记生成，参考事件 yᵢ；生成标签为 ŷᵢₖ：

```math
A_i=\frac{1}{K_i}\sum_k\mathbf{1}[\hat y_{ik}=y_i].
```

| 指标 | 计算方式 | 回答的问题 |
|---|---|---|
| 距离–准确率曲线 | 各距离桶内分别计算正负类点平均，再等权平均 | 模型越靠近边界是否越容易错？ |
| NearAcc | 近边界桶内：½ ×（参考正类平均 A + 参考负类平均 A） | 近边界两种结果是否都能生成？ |
| PairAcc | 同上下文跨边界配对，两端独立生成时为 A₋ × A₊，再按组聚合 | 是否正确响应跨界变化，而非始终生成同一结局？ |
| EventExact | 所有预登记关键事件标签及要求的时序关系全部正确，才得 1 | 是否沿正确过程到达结果？ |

必须附报：两侧各自分数、有效来源组数、生成失败率、事件不可判率、距离可计算覆盖率。距离桶缺一类时平衡分数为 NA；不能用单侧准确率冒充 NearAcc。

讲解：模型输出失败或事件不可判，在主正确率分母中保留并计未正确，同时拆分原因。不能只统计“生成成功且容易判读”的视频。

教学例子，**不是 T15 实测**：近边界两端各生成 5 次，分别正确 4 次和 3 次，则 NearAcc = 70%，独立 PairAcc = 0.8 × 0.6 = 48%。配对分数更严格。

## 第 6 页｜因果事件链与物理反演怎样结合？

T15 的参考链条可登记为：**书本接触笔记本 → 笔记本越缘 → 跌落 → 接触地面手机 → 手机运动**。

- 每个样本记录各节点是否发生；没有发生的节点同样是有效标签。
- 只对需要且发生的节点检查先后关系，不强迫所有样本完成整条链。
- 报告首次确定错误节点；与“首次无法判断节点”分开。
- 跨界配对进一步检查哪些节点消失、保留或出现。事件变化匹配不能替代两端本身都正确。

重力反演补充量化：

```math
\mathrm{RGE}=\frac{|\hat g-g_{\mathrm{requested}}|}{g_{\mathrm{requested}}}.
```

| 报告量 | 定义 |
|---|---|
| 请求重力偏差 | 有效拟合上的均值、中位数、P95；对于生成视频是与请求值的偏差 |
| 总登记覆盖率 | 有效拟合数 / 全部登记数 |
| 参考适用率 | 参考反演适用数 / 全部登记数 |
| 适用子集拟合覆盖率 | 有效拟合数 / 参考适用数；分母为 0 时 NA |

仅通过冻结契约、状态为 ok 的拟合计有效，at_bound 不计成功。参考视频可以衡量已知重力的估计误差；生成视频没有已知真实重力，不能把请求偏差直接称作真实参数估计误差。

**关键规则：不适合重力反演，不等于不适合临界分支评测。** 不跌落负例仍参加生成、NearAcc、PairAcc 和事件链评分。速度与摩擦已有独立开发模块，尚不作为冻结主指标；物体、时间窗和物理参数定义需要匹配。

## 第 8 页｜T15 的一组现成评测实例

| 条件 | 左端样本 | 右端样本 |
|---|---|---|
| 上下文 | 家庭背景、地球重力、同一 A 族 | 相同 |
| 书本初速度 | 2.016 m/s | 2.304 m/s |
| 参考跌落标签 | 0 | 1 |
| 重力反演参考资格 | 无笔记本跌落窗口，不适用 | 待冻结参考资格核验 |
| 是否保留分支评测 | 是 | 是 |

执行顺序：

1. 读取已有输入帧和实际参数；参考标签、边界和反演资格单独保存。
2. 模型只接收前置视觉条件、物理参数和对象说明，不接收结局或临界值。
3. 在共同观察窗内，独立标注生成视频的跌落与链条事件。
4. 计算分支、配对、事件链指标；适用输出另外进入物理反演。
5. 绑定原搜索边界后，计算距离分层；不需要重渲染恰好位于临界值的参考视频。

**当前这组没有绑定精确 θ*，因此 NearAcc 暂为 NA。** 两端参数的中点不能直接作为真值；也不把既往局部数值敏感性检查中的点宣称为唯一精确物理阈值。

## 第 10 页｜接下来用哪些实验检验贡献？

| 实验 | 设计 | 要验证的主张 |
|---|---|---|
| 距离分层主结果 | 同上下文、同目标事件，比较 Near/Mid/Far；报告双方覆盖 | 总体分数是否掩盖近边界失败？ |
| 跨界配对 | 跨界 PairAcc，与参数差距相近的同侧配对比较 | 失败是否与结果切换有关，而非任何参数变化都困难？ |
| 因果过程对照 | 最终结果正确率 vs EventExact；报告首次错误节点 | 终局正确是否掩盖错误的交互过程？ |
| 联合反演 | 分支正确/错误分别报告重力偏差、资格和覆盖 | 事件正确与动力学正确是否提供不同信息？ |
| 参数输入对照 | 完整参数输入 vs 不提供被干预参数；保持其余输入一致 | 模型是否使用显式物理条件？避免把视觉中仍可见的条件误称为完全移除 |
| 泛化 | 当前联合训练划分上的 ID、OOD-1、OOD-2，并分引擎报告 | 未见事件迁移中的分支、链条和参数表现 |

优先顺序：**绑定现有搜索记录 → 冻结 T15 合格来源组及事件定义 → 可靠独立标注 → 多种子生成 → 多模型比较 → 扩展其他场景。**

目前不默认需要补渲染。只有在明确选定的评测族确实缺少所需两侧样本，且历史库存和搜索记录无法补齐时，才讨论补采或缩小该项评测范围。

组会上希望确认的决定：事件终止窗、参数归一化跨度与距离桶、可靠事件标注流程，以及首轮模型/种子预算。不要预先承诺未经实测的准确率提升或会议录用结论。

## 备份 A｜边界真值与异常情况

- 优先采用版本匹配的原搜索记录或满足假设的解析计算，并记录判据、单位、上下文和观察窗。视频结果标签由逐帧状态/接触及必要视频审核确定，不只按 θ 的大小猜测。
- 若仅有边界区间 [a,b]，距离下界是点到区间的距离，上界是到两端距离的最大值；跨距离桶时标为分箱不确定，不强行取中点。
- 多次转换分别登记局部边界；命中→绕过等事件可能非单调，不强制拟合唯一阈值。
- 近边界结果对求解器设置敏感时，公开固定仿真契约与不确定性；不能据局部敏感性否定整个数据集。
- BoundaryError 是可选扩展：需要模型响应曲线能定位其翻转位置；它不是使用现有两侧视频评测的前提。
- 响应曲线同时画事件 0、事件 1、不可判三类比例，不删掉不可判后再归一化。

## 备份 B｜统计与划分口径

- 主聚合顺序：种子 → 参数点 → 族内正负类平衡 → 来源组 → 场景宏平均。单个族更多机位或重复不应主导总分。
- 置信区间按物理来源组 bootstrap，建议 2,000 次、95%；不能将 K² 个配对组合当作独立样本量。
- 独立种子 PairAcc 与共享种子的 CoupledPairAcc 分开；后者按同 seed 两端同时正确计分。
- Genesis + Isaac 联合训练；T03/T20 为 OOD-1，T11/T19 为 OOD-2，其余 16 类按来源组约 80/10/10。
- 当前完成事件池路由，最终组级 split 尚未落实；两类 OOD 是整事件迁移，不是纯拓扑或纯链长实验，也不是引擎留出。
- 同源视角、背景变体、反事实分支、重复及已知跨引擎对应关系绑定。GravTrace 既有开发数据与生成模型训练划分另行披露，不能把 OOD 名单当成指标从未开发使用的证据。
