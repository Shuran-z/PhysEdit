新8条使用[临界配对参考协议](../../benchmarks/critical_supplement_v1_20261101/README.md)，包含固定源revision、视频哈希、状态、条件图、三种英文提示词、原始静止保持和施力时序。`replacement_answers.json` 将每条绑定到新的Core100槽位，`retained_distance_references.json` 保留其余92条原有数值记录及适用性限制。

## 运行与成绩隔离

```powershell
python -m physedit.core100_rebalanced status
python -m physedit.core100_rebalanced export-replacements --out review/core100_v2_new8 --model MODEL_NAME --fps 24 --variant 1 --seeds 0 1 2
```

这会导出新8条的24个生成任务，附新Core100版本及槽位，同时保持原参考输入子版本和哈希。配置模型原生时长后沿用 `physedit.boundary run`、两阶段筛查与 `physedit.critical_supplement score`；后者检查新版槽位映射，成绩明确标为“新版100条中的8条”，不会冒充全100条成绩。

其余92条的输入对象逐项不变；已有输出和标签只有在参考、条件帧、prompt、生成窗口、视频哈希及协议完全对应时才可复用，不能仅凭相同槽位迁移。新8条必须对所有比较模型重新生成、独立标注。T05需6.833333秒窗口，旧固定124帧/24fps的H3适配器不能直接覆盖，禁止改FPS或截短窗口去凑。
