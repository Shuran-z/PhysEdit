# 全景视觉完整性筛查 scene-integrity-v2

2026-10-21。用户要求将原场景中没有的人头、人物/卡通角色、额外无关物体与场景替换加入垃圾视频筛查。此版本扩展视觉筛查范围，不增加物理事件正确性的自动判定。

## 规则

- 第一个实际送入裁判的图像为初始场景锚点。先记录初始物体、人物/角色（若存在）、家具和环境。
- 四项独立观察：`foreign_objects`（无关实体侵入）、`scene_replacement`（场景替换）、`identity_loss`（原对象身份丢失）、`geometry_corruption`（严重几何损坏）。检查整幅图像，包括背景；目标物体仍完整不能抵消背景侵入。
- 正常遮挡、旋转、出画、相机移动、光照变化不自动算损坏；由镜头显露的原有家具不自动算新增物体。清楚可判的错误物理、静止或事件错误继续留给物理评分。
- 每项输出`present/absent/uncertain`、整数采样序号与可见理由。`present`要求至少两个不同时间的**初始帧之后**的证据；初始帧只作为隐式对照。`absent`必须引用初始和末个采样，并检查中间图像。
- `contradictions`只用于同一图像的互斥解释或标签/理由冲突。明确的时间变化本身是缺陷证据，不是此字段所指的逻辑冲突。
- 程序把采样序号映射到实际送入模型的时间；序号越界、布尔值冒充整数、缺项和错误枚举作为评测器失败，不静默填补。
- 不使用未校准的自报置信度硬阈值。一个具备充分证据的缺陷可产生`auto_rejected`机器候选；全项具备首尾证据且均无缺陷才能`pass`；疑点/冲突/证据不足进入`review`。

机器拒绝候选和人工确认失败仍分开。所有登记样本保留，不删除媒体，不为未完成复核的样本伪造事件标签。此处视觉质量失败不等于所有目标事件都不可测，尤其是背景侵入；人工需记录具体受影响范围。当前通用两阶段入口对确认质量失败仍采用原有保守全事件阻断，分事件处理参见FAILURE_HANDLING.md。

## 调用

```bash
python -m physedit.qwen_boundary_judge --stage quality --quality-policy scene-integrity-v2 --manifest quality_jobs.jsonl --output quality_v2.jsonl --model /models/Qwen3.5-9B --frames 13 --max-new-tokens 1600
```

`--quality-policy`默认仍为`legacy`，旧实验可复现；事件调用不接受此新质量选项。协议中quality_command加入此参数即可通过既有`boundary_pipeline`路由，新格式由`policy_version`分派。默认旧质量和事件的0.9门槛保持原解释。

receipt保存实际提示、裁判源码/新策略源码SHA256、manifest哈希、图像哈希、实际采样帧和时间。新旧结果另存，不回写旧回答。

## 本轮验证边界

`review/quality_scene_v2_20261021`使用前轮完全相同的24条视频、哈希、目标描述、原生观察窗和13个时间点。策略、提示、证据表示与输出上限变化均记录；不是只改变一个变量的消融。先行5条校准输出保存在远端`attempt01`，校准后重跑全24条，不能选择性混合两次输出。

新增策略和相关流水线共13项针对性测试通过。扩大到继承的边界测试时，2个历史prompt构建测试因环境缺`sentencepiece`报错；此问题不影响本次已冻结视频的质量推理，未据此声称整套测试全部通过。
