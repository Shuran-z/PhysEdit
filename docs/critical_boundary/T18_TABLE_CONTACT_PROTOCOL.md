# T18 多书版：原配置条件下的触桌边界

2026-10-20用户选择：上层非抽取书散塌后接触桌面，与本轮T09的具体事件一致。旧两书版保持其原合同，不能与多书版拼接成同一条响应曲线。

## 当前机器可判事件

事件ID为`upper_nonpulled_book_on_table_at_end`：第209帧至少一本`experiment.supported_book_names`中的书，与原支撑桌面发生原生接触。主动抽取书不参与。它严格描述末帧触桌状态，不能代替“整段视频曾经触桌”、落地或所有形式的坍塌。

必须有求解器接触记录才判正。`static_geom_*`没有桌面语义名称时，使用原配置的`surface_z`定位已存在的接触点；接触点高度容差为该接触的穿透量加0.1mm，用于识别接触面，不是用书本下沉距离制造触桌事件。输出具体书名、静态实体、接触位置和穿透量。只下降、没有原生桌面接触的书不判正。

“触桌”和“散塌过程”分开描述：整堆平移或整体沉降不能仅凭触桌就宣称发生了整体坍塌。完整过程仍由事件链合同判读；本数值边界使用上述明确命名的触桌状态。

## 搜索规则

每条发布视频单独固定书本数量、抽取层、布局、资产、背景、重力和原种子。沿该版本原来的`overlap_length`或`contact_friction`网格搜索，先复现原视频参数点的事件结果，再分别向左右查找首次观测到的异类结果，并将局部区间细化至宽度不超过0.0005。

这是原网格上的局部条件边界，不声称排除了同类相邻网格点之间隐藏的额外翻转。原范围内没有观测翻转时，记录`no_observed_flip_on_original_grid`，保留参考视频和事件标签，不捏造临界值，也不因为缺少边界而删除样本。

归一化分母使用该版本原轴的完整扫描范围。一个样本左右都找到边界时，保存两个区间；“到最近已观测边界”的距离上下界分别取各区间距离上下界的最小值。源视频在事件准确率分母中只出现一次，不按区间数量重复计数。

500个已先行核验的配置和后恢复的67个旧版overlap配置分队列运行；均在首条原事件复现成功后才进入批量搜索。数值状态采用可无损解压的gzip保存，原始字节SHA256与压缩文件SHA256分别登记，原参考视频不修改。

## 管线入口

- `scripts/prepare_t18_table_contact_search.py`：对应实时原配置、发布状态、原种子和具体触桌对象。
- `scripts/t18_table_contact_boundary_worker.py`：固定每个原配置进行条件搜索。
- `scripts/register_t18_table_contact_distances.py`：核对完成任务和探测状态，将距离、归一化和分组结果接入总账；同时输出全部567条参考候选及未完成/失败/无翻转原因。
- `scripts/combine_recovered_boundary_distances.py`：合并已完成区间；数值分组不自动授予正式参考准入，也不替代生成视频的事件标注或独立的物理反演覆盖率。
