# T09 支撑层塌落判据与参数临界区间

2026-10-19，按用户“这个阈值帮我算”的要求计算。本文件给出**新增的几何操作定义**，不冒称找回了原历史数值判据。它描述抽书后的上层支撑高度变化，不直接给整体倾覆贴标签。

## 算出的高度判定值

当前发布配置中，被抽取的`t09_book_03`碰撞厚度均为`0.027 m`。以初始已沉降的第0帧为参考，对上方`t09_book_04`至`t09_book_07`计算末帧质心下降量：

`D_i = z_i(frame 0) - z_i(frame 209)`。

取原支撑层与下一层支撑高度之间的中间判别面：

`D_threshold = 0.5 × 0.027 = 0.0135 m = 13.5 mm`。

至少一本上层书满足`D_i >= D_threshold`，记“上层支撑层塌落”；另外保存每本书的下降量和受影响书本集合。水平运动不计入该下降量。上层整摞下沉时，内部相邻接触仍可保留，不能靠内部接触图不变判定未塌落。

这个半层高度是为区分两个支撑高度状态而明确选定的操作判据，不是新的材料常数、失稳力学定律，也不是参数轴上的临界摩擦系数。
