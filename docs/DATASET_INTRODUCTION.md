# PhysEdit

PhysEdit 是一个面向物理可控视频生成的数据集与评测项目。它以桌面上的日常物体交互为基础，通过改变重力、初速度、摩擦、质量和物体间距，研究视频生成模型能否响应物理条件的变化，并保持接触、支撑变化和多物体传递过程的一致性。

数据目录包含20类场景、72,000条视频记录，由Genesis和Isaac两套仿真环境构建。每类场景包含2,640条Genesis记录和960条Isaac记录，覆盖四种背景、五档重力和三个机位。场景包括斜面运动、偏心碰撞、抽取支撑、书本堆叠、多米诺传播及多物体接力。不同引擎和场景变体分别保留身份与参数定义。

每条视频配有三个英文prompt，分别侧重场景与初始条件、预设施力或控制时序、物理条件。三个版本使用相同的关键输入参数，不包含预期事件结果。配套清单提供视频哈希、仿真来源、参数、下载位置和审核状态，下载工具按统一名称组织视频与元数据。

PhysEdit的评测工具结合物理参数反演与事件结果判读。参数反演用于测量生成运动对应的重力、摩擦和初速度；临界边界评测用于检查模型在事件转变附近的响应、跨边界结果变化和事件链一致性。各指标按参考真值、观察范围及测量条件选择适用样本，并报告失败率与有效覆盖率。固定Core100协议包含80个ID案例及两组各10个OOD案例，另设80个候补案例。
